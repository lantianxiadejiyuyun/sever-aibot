## 实施边界

- 在现有单管理员、自建 Go 中继架构上完成能力，不因旧文档包名而改回另一套传输框架。
- 不将示例图表、仅保存参数、501 或无实际执行的按钮记为功能完成。
- 连接失败、平台不支持、缺少外部配置时明确展示原因，不能生成虚假结果。
- AI 写操作保留人工审批；不开放无人确认的任意 shell。
- 密码、私钥和 webhook/token 不进入公开文档、日志或前端持久存储。
- 本次实施先在本地验证。线上部署按照已有宝塔 API 约定执行，单独记录实际部署与验收结果。

## 最后缺口的实施结果

- 自动 NAT 打洞：已实现鉴权 UDP 会合、观测地址交换、同 socket 打洞及证书固定的 QUIC 直连；模拟 NAT 映射/过滤测试、错误证书/伪造注册拒绝、撤销和有界回退通过。真实跨网兼容性仍待验收，对称 NAT/UDP 被封可能必须中继。
- KCP/QUIC：真实 UDP 隧道已实现，使用可信 TLS 1.3 和既有票据/yamux；回环数据传输、证书拒绝、票据拒绝及关闭测试通过。须部署独立 UDP 端口和证书，不能复用 HTTP 反代。
- proxy：实现访问设备本机 HTTP CONNECT/SOCKS5 CONNECT，严格限定规则指定目标；端到端回显、拒绝越界目标及握手缓冲测试通过。没有任意目标、公网开放代理或独立代理账户。
- 流量额度：实现持久、原子的写入前预留，累计/月度 UTC 周期及重置；并发、去重、重启和失败关闭测试通过。失败写入占用预留，控制面不可用时受限流量停止；启用额度/限速/连接限制时禁止直连绕过，实际成功流量与额度分开。
- 普通 AI 对话：每次回退尝试和工具轮次独立记录模型、usage、价格与费用；失败/取消也保留证据，聚合避免重复计费，页面提供逐次记录。未知费用不作零，服务商最终账单仍需外部核对。

新增已验收：按任务默认模型路由、会话人工固定事实（版本冲突保护）、显式授权的长日志分段归纳与历史语义摘要。接口测试覆盖授权、所有权、失败/取消后证据持久化和并发释放；实际本地页面已验证默认模型创建、事实保存、摘要成功、失败提示和手机布局。真实外部供应商尚未验收。

本轮已补齐：P2P 规则与节点双重回退许可、目标就绪后才报告中继、1500ms 直连预算，UTC 每日 AI 用量／费用汇总（区分未知与零费用），AI 停止转发／执行已登记巡检动作（人工审批、过期快照拒绝与一次执行保护）、终端录制自动保留期清理（默认 30 天，可配置；保护活跃会话并保留历史），以及早期 0010 开发库缺失 AI 快照／计费字段的兼容迁移。迁移保留原会话和消息，不伪造缺失的历史模型、价格或提示词快照。

上一轮列出的五项核心实现缺口已补齐；这不表示线上部署、真实外部验收或上文后续版本/可选项已完成。实现范围与限制详见 [NAT 与 UDP 传输](NAT打洞与UDP传输.md)、[流量额度](流量额度.md)、[转发验收](转发与直连验收.md)。
