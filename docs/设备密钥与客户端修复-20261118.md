# 设备密钥与客户端连接修复（2026-11-18）

## 修复与验证

旧版 Windows 客户端的保存按钮只写配置，不启动 Agent，因此会呈现已断开、日志空；旧连接按钮读取磁盘配置，不应用表单中未保存的修改。新版将主按钮改为「保存并连接」，保留「仅保存配置」并明确尚未连接。密钥默认掩码，可主动显示/隐藏；保存、连接和收起时恢复掩码。

使用独立 LOCALAPPDATA 和虚构设备密钥完成真实 GUI 自动化，覆盖未保存修改应用、重试日志、断开、显示/隐藏、重启读取、托盘常驻和退出。用户已运行的旧程序未被操作。后台 Agent 异常结束时清理生命周期状态，避免无法重新操作。

服务端新增迁移 0021，创建和轮换设备密钥同时保存认证哈希及主密钥加密密文，AAD 绑定设备。已有密钥可验证当前哈希后原子保留，无需轮换。查看与保留接口要求 CSRF、step-up、会话限流和审计。主密钥轮换包含设备密文，失败整体回滚。节点密钥策略不变。

已通过全量 Go 测试与 vet、前端类型检查/构建、Windows 发布包完整性校验和本地浏览器二次验证查看/关闭清理。控制面实际 WebSocket 握手验证了用户提供的设备密钥有效；诊断连接随后关闭，不能当作用户电脑持续在线的证明。
