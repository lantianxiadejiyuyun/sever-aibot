# 节点流量额度

`limitTotalGb`、`limitKind`、`limitResetDay` 作用于节点所有中继转发的上传与下载应用数据总和，包括 TCP、HTTP、私有隧道、SOCKS 中继和 UDP 载荷。它不是网卡计数器：握手、帧头、TLS、重传等开销不计入额度。

## 配置

- `limitTotalGb`：十进制 GB（1 GB = 1,000,000,000 字节），向下取整为字节；0 表示不限制。负数、非有限值、超出 int64 字节范围或正值不足 1 字节均被 API 拒绝。
- `limitKind`：空字符串或 `total` 表示累计额度；`monthly` 表示按月重置。其他值被拒绝。
- `limitResetDay`：0 至 31。月额度中 0 等价于每月 1 日；其他值指定 UTC 当日 00:00 重置。当月不足该日期时取当月最后一天，例如 31 日额度在二月末重置。累计额度忽略该字段。

例如 `{"limitTotalGb":100,"limitKind":"monthly","limitResetDay":1}` 表示每月 UTC 1 日重新提供 100 GB 的上传加下载额度。UTC 月边界不随节点本地时区改变。

## 执行与持久化

开启额度的节点在每次应用载荷写入前通过控制连接申请额度，单次最多 65,535 字节。控制面在 SQLite 写事务中读取当前配置、去重并持久化额度预留，提交后才返回许可。并发连接、双向流和多个连接到同一数据库的控制面实例共享同一个预算，不能分别获得一份完整额度。节点收到许可后才写数据，额度不足时 TCP 可写入剩余额度后关闭；UDP 不发送被截短的数据报，剩余额度不足一个数据报时关闭该关联。

预留不退款：实际写入失败、超时、节点退出或回复丢失都可能消耗额度。额度用量因此是保守预留量，不保证等于实际成功写出的流量。控制面和节点进程重启不会归零数据库中的额度；不依赖节点内存恢复。许可最长有效 10 秒且不跨月边界，节点在写入前检查有效期。已开始但被网络阻塞的写入可能在期限后完成，仍归属于申请时的额度周期。本实现不承诺按物理网卡发送时间切割周期，也不承诺断电导致数据库丢失时保留额度。

控制连接或数据库不可用时，已启用额度的节点不能获取新许可，等待至多 10 秒后关闭对应转发。每块载荷增加一次控制面往返和一次数据库事务，适合优先保证额度正确性的场景；高吞吐或高控制链路延迟下会降低性能。

每日预留量和请求去重键保存在 `node_quota_daily`、`node_quota_reservations`（迁移 0019）。相同请求 ID 和相同请求大小不会重复扣除；同 ID 不同大小被拒绝。去重键目前不自动清理，数据库会随载荷块数量增长。节点不重试超时的额度申请，也不会把旧许可用到新的写入。

累计额度包含部署本实现后产生的全部预留；月额度按当前周期起始日查询历史每日预留。修改额度数值不会清空已用额度，修改重置日或周期类型会用新周期重新解释现有日记录。关闭额度期间的流量不预留，不会在重新开启时补扣。历史流量报表也不回填为额度用量，避免把无法可靠归属的旧数据当作已执行额度。

## 查询与流量报表

已登录用户可查询 `GET /api/v1/nodes/{id}/quota`：

```json
{
  "limitBytes": 100000000000,
  "reservedBytes": 1024000,
  "remainingBytes": 99998976000,
  "periodStart": "2026-11-01",
  "resetAt": 1796083200
}
```

`resetAt` 为 UTC Unix 秒；累计额度的 `periodStart` 为空且 `resetAt` 为 0。`limitBytes` 为 0 表示不限额，此时 `remainingBytes` 为 0 不表示耗尽。达到额度后无需修改配置：下个周期第一次申请会自动使用新周期预算，已关闭的客户端连接需要重新建立。

既有转发流量报表仍统计成功写入的上传、下载字节，并按上报 ID 去重。它与额度预留互相独立，不会通过延迟上报再次扣额度。流量报告的待确认队列仍在节点内存中，节点异常退出可丢失尚未上报的数据；这不恢复已扣额度，也不影响额度上限，但实际流量报表可能少计。

## 直连与升级边界

节点配置额度后禁止 P2P 直连，使用中继路径执行额度；如果转发禁止中继，该转发将不可用。直连流量不经过节点，当前没有可信的直连额度执行机制。运行时配置更新需要送达节点后才开始执行新限制；启用额度前已经在途的写入仍可能完成。更新控制面、节点、Agent 为支持该协议的一致版本后使用本功能，旧节点不会执行新的配额请求协议。

测试覆盖并发预留、数据库重开、请求去重、跨月/闰年/月底日期、配置变更保留用量、TCP 精确剩余额度和 UDP 不截断发送。
