# Windows 客户端

Windows 桌面客户端在一个原生图形程序内运行现有 Go Agent，支持连接配置、运行状态、日志、托盘常驻和当前用户登录后自动启动。控制面及隧道能力与 `cmd/agent` 共用实现。

界面采用接近 iOS App 的窄幅竖向布局（固定宽度 460，默认高度 700），禁止横向拖动调整宽度和最大化，仍可纵向调整高度、浅灰背景、白色圆角卡片和全宽蓝色主按钮。顶部显示连接状态与操作提示，设备、网络、启动偏好和日志位于可滚动区域，底部操作按钮保持可见。设备卡片提供控制台链接，可在浏览器中获取设备 ID 和密钥；输入框、下拉框和按钮仍保留 Windows 原生交互与键盘操作。

## 使用

1. 将发布包解压到固定目录，运行 `AIBOT-Client.exe`。不需要管理员权限。
2. 在控制台「设备」创建 Windows 设备，复制设备 ID 和设备密钥。密钥会加密保存，之后可在设备详情二次验证后再次查看。
3. 在客户端填写控制面地址（默认 `https://aibot.eugenweb.cn`）、设备 ID 和设备密钥。这里填写设备密钥，不是控制台管理员密码。
4. 点击「保存并连接」。这个按钮保存当前表单并立即启动连接；「仅保存配置」不会启动连接。在状态显示「已连接控制面」后，可到控制台确认该设备在线。
5. 需要访问本机回环服务时，回环端口可填写 `3389,5432`，或填写 `*` 放行全部 1–65535 端口。允许网段可填写 IP/CIDR（逗号分隔），或填写 `*` 放行全部 IPv4/IPv6 网段（含链路本地地址）。两项均填写 `*` 即放开普通目标地址与全部回环端口；云元数据、未指定地址和组播地址仍由底层策略拒绝。留空时保持原有默认限制。

「访问预设」下拉框提供默认内网、全部放开、内网 + 本机 Orca（6768）、内网 + SSH/RDP（22,3389）、内网 + Web 开发（3000,5173,6768,8000,8080）及自定义。选择后只填入两项配置，保存并连接才生效；手动修改任一项会切回自定义，连接期间禁止更改预设。

更改配置前先断开连接。首次连接失败、网络中断或控制面临时不可用时，客户端会持续自动重连，没有重试次数上限。顶部显示「等待重连」和「N 秒后自动重连（第 M 次）」，实际发起连接时显示「正在重连」；重试等待采用随机指数退避，上限从 1 秒逐步增加到 60 秒，控制面确认连接成功后重置。连接已建立但尚未收到控制面确认时，不会显示设备已在线；无控制帧超过 90 秒会关闭失活连接并重试。

点击「断开」会取消当前连接和待执行的重试，网络或服务器恢复后仍保持断开，直到再次点击「保存并连接」或托盘连接菜单。关闭窗口仅隐藏到托盘，不会停止重连；退出进程后，下次启动仍按「启动后自动连接」设置执行。身份或地址不正确时应断开并修改配置，重试不会修复错误凭据。同一设备 ID 不要同时交给命令行 Agent 和桌面客户端运行，避免两者争用控制面连接。

## 后台常驻

- 关闭窗口会隐藏到通知区域，Agent 继续运行；通过托盘菜单恢复窗口。
- 重复启动客户端会恢复已有窗口，避免同一账户重复运行。
- 托盘的「退出」会停止 Agent 并退出进程；「断开」只停止连接，保留界面。
- 「登录后启动」默认关闭。启用并保存后，通过当前用户的 Windows Run 注册表项启动，启动参数为 `--background`，不包含设备密钥。
- 「启动后自动连接」控制是否使用已保存的配置建立连接。需要登录后自动连接时，应同时启用这两个选项。
- 此版本为用户会话内托盘程序，不是 Windows 系统服务；注销、关机后停止，登录后可按设置重新启动。休眠或网络中断后恢复时，Agent 自动重连。
- 开启登录启动后应保持 EXE 路径不变；移动目录后从新路径启动并重新保存设置。

## 配置与密钥

配置位于 `%LOCALAPPDATA%\AIBOT\Client\config.json`。设备密钥通过 Windows DPAPI 在当前用户范围加密，磁盘只保存加密数据；复制配置到另一账户或计算机不能直接使用。密钥不放入命令行、启动项或日志。

窗口中的设备密钥默认掩码显示，可点击「显示密钥」查看已保存的密钥，再点击隐藏。保存、连接和关闭窗口时恢复掩码。旧控制面只存哈希的设备可以在设备详情点击「保存现有密钥」，匹配验证通过后加密保留，不需要轮换或断开。

日志按「本地时间 · 信息/提醒/错误 · 中文事件」显示，省略重复设备 ID 和连接地址，常见连接失败提供中文原因与处理提示。取消「实时更新」可暂停界面刷新以阅读旧记录，后台仍继续记录；勾选后显示最新记录。「清空日志」只清除日志，不影响连接。日志仅保留当前进程内最近约 64 KiB，不写日志文件。退出客户端后日志清空。

停用客户端时，先取消登录启动并保存，再退出；如不再管理此设备，在控制台撤销或删除设备。删除本地配置不等于撤销控制面上的设备密钥。

## 构建

使用项目要求的 Go 工具链（当前 `go.mod` 为 Go 1.27.3），在 Windows PowerShell 执行：

```powershell
./scripts/build-windows-client.ps1
# 或构建 EXE 并生成包含使用说明和校验值的 ZIP：
./scripts/package-windows-client.ps1
# Go 未加入 PATH 时：
./scripts/package-windows-client.ps1 -GoExe 'C:\path\to\go.exe'
```

客户端使用原生 Windows 控件及系统托盘，无需安装 Node.js、浏览器运行时或 WebView2。构建脚本生成包含 Windows manifest 的 GUI 程序，运行时不弹出控制台窗口。

发布包未使用商业代码签名证书签名。
