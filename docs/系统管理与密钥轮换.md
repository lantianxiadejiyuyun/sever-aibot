# 系统管理与主密钥轮换

## 系统设置与登录会话

设置页提供站点名称、公告、审计保留期（7–3650 天）及终端录制保留期（1–3650 天，默认 30 天）。修改设置、结束登录会话需要二次验证。站点公告只作为纯文本显示。

审计保留策略在控制面启动时及此后每天执行，缩短保留期会删除超期审计。导出接口 `/api/v1/audit/export` 导出最近 500 条，CSV 对可能被表格软件当作公式的文本加前缀保护。

终端录制清理也在启动时及此后每天执行，以会话结束时间计算期限，只删除超期已结束终端的录制输出和 resize 事件，保留访问历史、结果与字节统计。进行中的会话不清理。删除与过期标记在同一事务内完成；历史列表显示“录制已过期清理”，再次请求录制返回 `410 recording_expired`。缩短保留期会在下一次清理时永久删除内容；延长保留期不会恢复已清理数据。SQLite 删除后复用空闲页，不保证数据库文件立即缩小，也不替代磁盘或备份的安全擦除策略。

`GET /api/v1/auth/sessions` 仅列当前管理员的有效会话；`DELETE /api/v1/auth/sessions/{id}` 撤销指定会话。当前会话被撤销时清除 Cookie。

## 账户与双因素认证

设置页支持修改管理员密码、绑定 TOTP 验证器、重置恢复码和禁用双因素认证。绑定密钥 10 分钟内有效；恢复码只在生成时显示，数据库只存哈希。TOTP 种子通过主密钥加密。

启用后，登录需密码与验证码或一次性恢复码。已使用的 TOTP 时间步不能重复使用；恢复码并发使用时只有一次成功。账户安全变更会撤销其他会话，并清除当前会话的二次验证状态。

高风险变更审批要求已启用 TOTP，并提交新的六位验证码；恢复码不能代替高风险审批验证码。同一时间步的验证码已经用于登录后，需等待下一验证码再进行高风险审批。

## 离线轮换主密钥

工具：`go run ./cmd/vault-rotate`，生产建议先构建成独立二进制。

1. 停止控制面，确认无其他程序使用数据库；通过已有部署流程操作生产服务。
2. 备份 SQLite 数据库及现有密钥配置，保持二者对应，备份不得进入代码仓库。
3. 在受保护的环境中配置 `AIBOT_DB`、原 `AIBOT_MASTER_KEY` 和新的 `AIBOT_NEW_MASTER_KEY`。两把密钥均为 32 随机字节的 Base64 编码。不要通过命令行参数传密钥。
4. 运行工具。工具在一个事务内重新加密凭据、通知渠道与管理员 TOTP 种子；旧密钥错误或任意记录解密失败时不提交。
5. 成功后，将服务环境中的 `AIBOT_MASTER_KEY` 更新为新密钥，移除临时新密钥变量，再启动控制面。
6. 验证已登记凭据的连接测试和通知渠道配置读取。新数据库不可与旧密钥混用；回退必须同时恢复对应的数据库备份和密钥。

工具不会输出任何密钥或解密内容，只报告处理条数。该工具是维护工具，不是在线轮换 API；运行中的控制面持有内存密钥，不能在其继续运行时轮换数据库。
